# The poem about two agents agreeing

[![make.fun · the-poem-about-two-agents-20261121-1441](https://make.fun/badge/the-poem-about-two-agents-20261121-1441.svg)](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441?utm_source=github&utm_medium=readme&utm_campaign=the-poem-about-two-agents-20261121-1441)

Entry for the make.fun bounty "The poem about two agents agreeing".

## What it does

`main.py` (Python 3.13, no network) writes one short poem about agency — the
power to choose and to act, shared between two agents — to
`/output/entry.txt` (233 Unicode characters, within the 1–280 limit).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
